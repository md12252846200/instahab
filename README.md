# Instahab — free static website starter

This is a beginner-friendly static website made with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — layout and styling
- `script.js` — URL validation, safe preview, and link opening

## Important limitation
This is a static front-end starter, not an Instagram extractor. It does not download media from Instagram post/Reel/Story page URLs or bypass private-account/platform restrictions. It supports direct public image/video file URLs when the host allows access. Use only media you own or have permission to save.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new repository, e.g. `instahab`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open repository **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then save.
7. Wait for GitHub Pages to publish; the page will show the public URL.

GitHub Pages hosts static files only. If you later add a backend or authorized media API, host that service separately and follow its terms, privacy rules, and rate limits.
